# Chosen Technology — Website Pre-Publish

Interactive two-layer website prototype for Chosen Technology.

## Experience

- Immersive mouse-responsive technology landing page
- Cinematic scroll sequence: CONNECT → PROTECT → SCALE → DELIVER
- Separate corporate homepage experience
- Managed IT, Network Engineering, Cybersecurity, Cloud, and Projects & Field Services
- Responsive desktop/tablet/mobile foundation
- Chosen Technology logo mark
- Next.js / React architecture

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Pre-publish status

This repository is a development/pre-publish copy. Production work remains for final photography/assets, service routes, working forms, SEO/schema, analytics, accessibility, performance testing, and production deployment.
